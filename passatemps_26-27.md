# Activitat passatemps

## passatemps.html

Heu de crear una web que es digui passatemps.html
Utilitzeu CSS Extern.

- Aquesta pàgina tindrà com a títol de pestanya i visible a la pàgina "Passatemps X", on X és el teu cognom.
- Hi haurà tres fitxes de passatemps amb una imatge i text:
  - Cada fitxa canviarà una mica quan el ratolí passi sobre ella: hover.
  - Cada fitxa té un títol del tipus de passatemps.
  - Cada fitxa té una imatge del tipus de passatemps.
  - Cada fitxa és un link a una pàgina: passatemps1.html, passatemps2.html, passatemps3.html.
